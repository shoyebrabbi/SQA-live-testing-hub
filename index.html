অ্যাকাউন্টে প্রবেশ

আপনার অ্যাকাউন্ট দিয়ে SQA পরীক্ষণ হাবে প্রবেশ করুন।

নিরাপদ প্রবেশের জন্য Supabase Auth ব্যবহৃত হয়।

নতুন অ্যাকাউন্টের জন্য প্রকল্পে ইমেইল নিশ্চিতকরণ চালু থাকলে, ইমেইল নিশ্চিত করার পর লগইন করুন। ডেটা ব্যবহারে Supabase টেবিলগুলোর Row Level Security (RLS) নীতিও সঠিকভাবে সেট করুন।

ব্যবহারকারী নিবন্ধন পরীক্ষা

ইনপুট যাচাই, সীমামান বিশ্লেষণ (Boundary Value Analysis) এবং ভূমিকা-ভিত্তিক প্রবেশাধিকার (RBAC) অনুশীলন করুন।

ইচ্ছাকৃত বাগ: ১৭ বছর বয়সের সীমার নিচের মানটি জাভাস্ক্রিপ্ট যাচাই এড়িয়ে সংরক্ষণের চেষ্টা করে; ডেটাবেসের নিজস্ব নিয়ম থাকলে সংরক্ষণ প্রত্যাখ্যাত হবে। রিসেট বোতামটি ইনপুট পরিষ্কার করে না।
নিরাপত্তা সতর্কতা: এই ফর্মের আসল পাসওয়ার্ড ডেটাবেসে রাখা হয় না; নির্ধারিত কলামে কেবল অ-গোপন পরীক্ষণ চিহ্ন রাখা হয়। নিরাপদ প্রমাণীকরণ ও হ্যাশিং Supabase Auth পরিচালনা করে। ভূমিকা নির্বাচকটি শুধু UI-তে থাকে, কারণ নির্ধারিত টেবিলে Role কলাম নেই।
